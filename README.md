# Mesto — интерактивная фотогалерея

**Учебный фронтенд-проект Яндекс Практикума**: страница профиля и фотокарточек с возможностью редактирования данных и взаимодействия с сервером.

> **English:** JavaScript photo-gallery application with API integration, profile editing, image cards, likes, form validation, and Webpack tooling.

## Возможности приложения

- Загрузка профиля пользователя и карточек с API.
- Редактирование имени, описания и аватара профиля.
- Добавление карточек с фотографиями, просмотр изображений в модальном окне.
- Лайки и снятие лайков; удаление собственных карточек.
- Проверка полей форм и управление состояниями модальных окон.
- Обработка асинхронных запросов и состояний загрузки.

## Стек

`JavaScript (ES modules)` · `HTML5` · `CSS3` · `BEM` · `Fetch API` · `Webpack 5` · `Babel` · `PostCSS`

## Структура проекта

- `src/index.js` — инициализация приложения и обработчики интерфейса.
- `src/scripts/api.js` — запросы к API.
- `src/scripts/card.js` — создание карточек, лайки и удаление.
- `src/scripts/modal.js` — работа с модальными окнами.
- `src/scripts/validation.js` — валидация форм.
- `src/blocks/` — стили компонентов по БЭМ.

## Локальный запуск

```bash
npm install
npm run dev
```

Сборка для размещения:

```bash
npm run build
```

Приложение использует учебный API Яндекс Практикума. Для корректной работы серверных операций требуется доступность этого API и действующая авторизация.

## Чему посвящена учебная работа

Проект закрепляет DOM, обработку событий, модальные окна, формы, асинхронный JavaScript, REST API, модули и сборку Webpack.

**Программа:** [Яндекс Практикум — «Веб-разработчик»](https://practicum.yandex.ru/web/).

*Это учебный проект, а не production-сервис.*
